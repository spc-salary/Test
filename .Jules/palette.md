## 2025-08-14 - Focus State & Semantic Markup Enhancement in Neumorphic UI
**Learning:** Neumorphic design patterns naturally obscure the default keyboard focus states of interactive controls because they lack borders and rely heavily on subtle box shadows. For assistive technologies, a live element like a timer must have explicit aria-live properties, and dynamic buttons must have contextually updated aria-label attributes. Additionally, using raw `innerHTML` for dynamic task list additions poses XSS vulnerabilities and makes it difficult to provide semantic, keyboard-accessible action controls like a deletion button.
**Action:** Define explicit, high-contrast `:focus-visible` styles matching the accent color for all buttons and inputs. Use `aria-live="polite"` on the active timer display. Ensure dynamically loaded lists use `document.createElement`, avoid `innerHTML`, and use semantic `<button>` tags with descriptive, dynamic `aria-label` attributes for accessibility.
