## 2025-05-18 - Focus Visibility in Neumorphic UI Design
**Learning:** Neumorphic visual designs naturally remove standard browser focus outlines (`outline: none`) for aesthetic reasons, rendering the interface completely invisible to keyboard navigation users.
**Action:** Always provide explicit `:focus-visible` styles with custom outlines or offsets for interactive elements in neumorphic designs so keyboard focus is clear without compromising mouse aesthetics.
