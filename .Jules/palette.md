## 2023-11-22 - [Accessible Task Operations and Visual Feedback in Minimalist Interfaces]
**Learning:** In minimalist neumorphic designs, visual affordances like focus outlines and interactive elements are often removed (e.g., using `outline: none`) to maintain a clean aesthetic, severely harming keyboard accessibility. Standardizing focus-visible indicators and replacing non-semantic text elements (like "x" span elements) with accessible `<button>` tags with `aria-label` retains the clean aesthetic while satisfying critical accessibility needs. Additionally, in-tab timers benefit greatly from dynamic document/tab title updates to keep users informed without breaking flow.
**Action:** Always replace non-semantic click actions with semantic, accessible interactive elements. Never strip standard focus indicators without replacing them with highly visible custom `:focus-visible` styles that respect the design system.
