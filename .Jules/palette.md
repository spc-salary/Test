## 2024-07-29 - [Keyboard Focus and Semantic Elements]
**Learning:** In highly customized minimalist/neumorphic UI designs, default focus outlines are frequently disabled using `outline: none;` to maintain visual aesthetics. However, this completely isolates keyboard users who cannot see which element is currently active. Furthermore, using non-semantic elements like `<span>` with `onclick` handlers for key interface elements (such as deleting tasks) prevents screen readers and keyboard users from focusing or interacting with them.
**Action:** Always provide custom `:focus-visible` styles matching the brand's aesthetic (like a clean solid border or inset/outset shadow in the accent color) and replace interactable `<span>` tags with accessible semantic `<button>` elements with clear `aria-label` tags.
