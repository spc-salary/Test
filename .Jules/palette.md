## 2026-11-01 - Accessible Focus States and Dynamic Action Elements in Neumorphic Interfaces
**Learning:** Neumorphic soft-shadow designs typically suppress default outlines with `outline: none` to preserve aesthetic soft borders, making keyboard navigation completely invisible to screen readers and keyboard users. Additionally, relying on non-semantic clickable spans without keyboard focusability or dynamic aria-labels degrades accessibility for screen readers and creates XSS vulnerabilities when inserting user-provided task text.
**Action:** Always provide explicit `:focus-visible` styling using the design system's accent color and offset, and generate semantic `<button>` elements with descriptive `aria-label`s and `textContent` rather than `innerHTML` when creating dynamic interactive items.
