# Palette's Journal - Critical UX/Accessibility Learnings

This journal documents critical UX and accessibility insights discovered during the enhancement of the Minimalist Pomodoro application.

## 2025-07-27 - Initial Setup
**Learning:** Neumorphic design elements like buttons and inputs lack visible focus indicators, making them difficult to navigate using keyboards.
**Action:** Always add custom, accessible focus-visible styles that match the neumorphic aesthetic without breaking keyboard accessibility.
