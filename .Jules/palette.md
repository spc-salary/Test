## 2024-11-11 - Accessible Focus and Controls in Neumorphic UI Design
**Learning:** Neumorphic design systems rely on subtle dual drop shadows (`box-shadow`) and often strip default browser outlines via `outline: none`, completely obscuring active keyboard focus and making navigation invisible to keyboard users. Additionally, relying on non-interactive elements like `<span>` for deletion actions without keyboard focus or accessible labels prevents assistive tech users from managing items.
**Action:** Always provide explicit `:focus-visible` styling using the theme's primary accent color with `outline-offset` to preserve neumorphic aesthetics while meeting WCAG 2.4.7 focus visibility requirements. Use semantic `<button>` elements with descriptive, context-specific `aria-label` attributes for icon-only actions.
