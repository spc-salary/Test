## 2025-05-18 - Focus Visibility in Neumorphic UI
**Learning:** Neumorphic CSS design relies heavily on soft shadows and subtle background contrasts, which native focus states often fail to cleanly overlay. Explicit `:focus-visible` rings with offset are critical for keyboard navigation in soft-UI patterns.
**Action:** Always inspect `:focus-visible` on soft/neumorphic button and input components and add high-contrast focus rings that do not rely on standard browser default outlines.
