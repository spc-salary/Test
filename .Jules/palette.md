## 2026-08-13 - Neumorphic Visual Accessibility and Safe Task Rendering
**Learning:** Neumorphic design systems naturally suppress visible element borders and standard focus states to maintain their "soft-extruded" aesthetic. This causes significant keyboard navigability issues because users cannot determine which element is currently focused. Additionally, rendering task deletions with raw `innerHTML` spans exposes applications to XSS vulnerabilities and lacks screen reader context.
**Action:** Always implement explicit, matching `:focus-visible` styling using focus-ring accents on interactive neumorphic elements. Ensure any dynamically generated list components use safe DOM generation APIs (`document.createElement`, `textContent`) instead of `innerHTML` and use semantic `<button>` tags with descriptive dynamic `aria-label` tags for control or deletion elements.
